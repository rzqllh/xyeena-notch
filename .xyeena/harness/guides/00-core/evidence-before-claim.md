# Evidence Before Claim Harness
Mode: CORE

Do not claim a state that has not been verified.

Examples:
- "Build passes" requires the relevant build command.
- "Responsive" requires viewport verification, not CSS inspection alone.
- "Fixed" requires reproduction or a direct regression check.
- "Secure" is never inferred from code appearance alone.
- "Merged/deployed" requires remote evidence.

When verification is impossible, say exactly what was and was not verified.
