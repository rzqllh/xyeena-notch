# Continuation Harness
Mode: CORE when continuing prior work

Repository truth outranks an old agent summary.

Before continuing:
- inspect branch/worktree
- inspect recent commits
- inspect divergence from target
- inspect open PR/CI state when relevant
- identify latest verified checkpoint
- detect work already completed

Resume from the first incomplete checkpoint.
Never duplicate commits, pushes, PRs, merges, or edits merely because an older plan listed them.
