# Repository, AI Artifact & Documentation Hygiene
Mode: CORE near commit/release

Before commit/push:
- inspect untracked/generated files
- remove debug logs and scratch artifacts
- do not track prompt dumps/session notes unless intentionally part of the product
- no Codex/GPT/bot PR comments unless requested
- documentation describes shipped reality, not intended future state
- public docs do not leak secrets/private architecture/internal-sensitive terminology
- naming and file placement follow existing project conventions
