# Accessibility Harness
Mode: TRIGGERED for user-facing UI
Default target: WCAG 2.2 AA where applicable.

Check:
- semantic HTML
- keyboard operation
- visible/unobscured focus
- labels/names
- contrast
- headings
- screen-reader status announcements
- form errors
- dialog semantics
- pointer target sizing
- alternatives to drag-only interactions
- reduced motion
