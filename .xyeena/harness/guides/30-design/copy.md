# Product Copy Harness
Mode: TRIGGERED for user-facing text

Prefer clear, specific language over performance prose.

Reject:
- generic inspirational copy
- jargon when plain language exists
- repeated triads/tagline formulas
- unnecessary microcopy
- labels that describe implementation instead of user intent
- artificial "premium/modern/seamless/elevate" filler

Error copy must explain what happened and the next action when known.
