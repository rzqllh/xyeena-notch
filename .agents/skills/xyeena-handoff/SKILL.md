# Handoff

Build the handoff from persisted state plus current repository facts, not memory alone. Include: goal, current workflow state, locked decisions, verified facts with freshness, open unknowns, rejected alternatives with reasons, scope, completed/active/blocked tasks, relevant artifacts, current git state and next executable action.

Exclude conversational filler and superseded hypotheses. Mark stale evidence instead of carrying it forward as truth.
