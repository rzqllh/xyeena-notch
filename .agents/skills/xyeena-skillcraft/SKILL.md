# Skillcraft

Write the smallest instruction layer that changes behavior. Keep always-loaded descriptions precise because they are activation pointers and permanent context cost. Put branch-specific reference material behind relative pointers.

Give procedural steps observable completion criteria. Prefer positive target behavior over long prohibition lists. Keep one source of truth for each rule; do not restate environment facts the agent can cheaply inspect.

Test three things: the skill fires when it should, stays quiet when it should not, and changes behavior in the intended direction. For important skills, compare baseline behavior without the skill against behavior with it and capture rationalizations that bypass the intended discipline.
