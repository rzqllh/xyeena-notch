# Plan

Plan from locked intent, not from guesses. Identify scope as `REQUIRED`, `ALLOWED`, and `OUT_OF_SCOPE`. Break work into tracer-sized tasks that produce testable progress; declare dependency edges and file/interface ownership where known.

Each task must state its observable completion criterion and verification method. Avoid ceremony for trivial reversible work. Do not pre-build abstractions for hypothetical future requirements.

A plan is ready when an executor can act without rediscovering product intent, while retaining enough judgment to handle normal implementation details.
